# DSH 情感聊天
一个基于弗洛伊德心理动力学引入双驱情绪模型的 Deepseek Harness插件。它模拟了力比多（生本能/爱欲）与攻击性（死本能/毁灭欲）之间的相互作用。LLM的回复与交互将根据这两种核心心理能量的浮动平衡而动态演变，提供独特的、基于心理学基础的陪伴体验。
这个插件让 DeepSeek Harness 的角色把同一段关系延续到不同聊天里。你可以给每个预设写一段人格、勾选它能用的工具，再在设置页查看角色当前的好感度和四项驱力。接管开关默认全部关闭，插件只对已启用角色的顶层聊天生效。

**记忆功能** · 无。跨聊天延续的是好感度、驱力和互动进度。近期对话仅用于当次情绪分析。

## 安装

插件当前版本为 0.2.0，适配 DeepSeek Harness 0.2.2-rc.5 的桌面端和 Web profile。

### 通过 npm 安装

包名是 `@atmluck/dsh-plugin-affection`。包发布后，在 DSH 侧栏打开「插件 → 添加插件」，输入包名即可；也可以运行下面的命令。[npm 包页面](https://www.npmjs.com/package/@atmluck/dsh-plugin-affection)

```sh
dsh plugin --profile web add @atmluck/dsh-plugin-affection
```

在 DSH 标准模式里，也可以直接对模型说「请通过 npm 安装情感聊天插件，包名是 `@atmluck/dsh-plugin-affection`。」装好后，到 DSH 插件详情的「版本」里，就能检查并安装适配的新版本。

### 从本地安装包安装

在存放发布包的目录运行以下命令。

```sh
dsh plugin --profile web add ./<包名>.tgz
```

在 DSH 标准模式里，也可以直接对模型说「请从`https://github.com/ATMLuck/dsh-plugin-affection.git`安装情感聊天插件」装好后，到 DSH 插件详情的「版本」里，就能检查并安装适配的新版本。

## 配置第一个角色

1. 在 DSH 里打开 **设置 → 情感聊天**，选一个已有预设；或者点人格提示词旁边的 **新建预设**，输入名称。新预设会出现在 DSH 的预设列表里，插件重载后也不会丢。
2. 填写**人格提示词**，比如「你是海岸观测员。说话简短，喜欢用天气和潮汐解释日常见闻。」这段文字会原样成为该预设的完整系统提示词，`{{…}}` 之类的内容也不会被替换。情绪快照由插件另外注入。
3. 勾上这个角色能调用的工具；一个都不勾就是纯聊天。最后打开**接管此预设**并保存。
4. 新建或重新加载使用该预设的会话。发送一条消息后，回到设置页就能看到档案。以后修改已接管角色的人格或工具名单，会在下一轮聊天生效。

设置页每 5 秒刷新一次预设列表和当前情感数值，正在编辑的草稿不会被冲掉。多个窗口同时改同一个预设时，保存会提示冲突，需要重新载入。切换查看哪个预设，不会改动接管开关。

## 聊天与情绪更新

普通聊天只生成一次主回复。模型需要用工具时，可以在第一步请求一批已勾选的工具，审批和执行交给 DSH；拿到结果后，第二步不带工具地给出最终答复。

每个预设都有独立的情绪档案，同一存储范围内的多个聊天共用它。默认好感度 50（范围 0～100）；对用户和对自身各有力比多、攻击性两项驱力，默认都是 25（范围 0～50）。

第一次真人互动只计数、不分析。从第二次起，插件在后台把本轮输入、最近最多 2,000 字符的对话和情绪快照交给分析模型；分析失败就保留原数值。注入的情绪提示默认每 5 个有效互动轮刷新一次，四项当前驱力会在 2 小时内慢慢回到各自的基线。连续空闲满 6 小时，还会再评估一次。

## 查看与调整情感数值

在「设置 → 情感聊天」里选中一个预设。表格列出好感度、四项驱力的当前值和驱力基线；表格上方显示对你的情感、自身状态和互动轮数。

打开表格下方的 **允许编辑情感数值**，就能直接改当前值。点 **保存情感数值** 后，四项驱力会从新数值继续向各自基线回归。基线列只读；好感度没有基线。

编辑模式下还有三项重置操作：

| 操作 | 效果 |
| --- | --- |
| 当前驱力恢复到基线 | 四项驱力回到各自基线 |
| 重置关系与互动轮数 | 恢复初始好感度和对用户的驱力，保留自身的两项驱力 |
| 重置全部情绪与互动轮数 | 恢复全部初始数值，保留人格和工具设置 |

## 高级配置

下面这些选项写在 DSH profile 中 ID 为 `affection` 的插件配置里，对当前实例管理的角色生效。

| 配置项 | 默认值 | 作用 |
| --- | --- | --- |
| `initialAffection`、`fullAffectionPresets` | `50`、`[]` | 初始好感度；名单中的预设从满好感 100 开始 |
| `initialDrives` | 四项均为 `25` | 设置四项驱力的初始值与基线。字段为 `libidoOther`、`aggressionOther`、`libidoSelf`、`aggressionSelf` |
| `sensitivity` | `30` | 按百分比调整互动对当前驱力和好感度的影响 |
| `lockTurns`、`decayHours` | `5`、`2` | 一段情绪提示覆盖多少互动轮，以及当前驱力回到基线的小时数 |
| `idleEnabled`、`idleHours` | `true`、`6` | 是否评估空闲状态，以及触发所需的连续空闲小时数 |
| `analysisRoute` | 跟随会话模型 | 指定分析用的 `provider` 和 `model` |
| `analysisTimeoutMs` | `30000` | 后台分析的超时时间，单位为毫秒 |

## 卸载

```sh
dsh plugin --profile web remove @atmluck/dsh-plugin-affection
```

卸载后，重新加载已接管的会话，就会恢复原预设自己的工具执行器。
